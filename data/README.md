# Datos

`data/input/` contiene archivos de una corrida.  
`data/reference/` contiene tablas mensuales de referencia.  
`data/sample/` contiene datos ficticios o sanitizados aptos para desarrollo y documentación.

En el proyecto privado, `input` y `reference` pueden contener información confidencial y no deben versionarse sin revisión. Los datos de `sample` sí podrán versionarse en el futuro cuando sean ficticios o sanitizados.
